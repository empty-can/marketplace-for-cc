### hooks（本調査の「hook で強制する」方針に関係）

- **hooks reference「Block the action when a hook fails」が新設**（v2.1.295 以降）: command / HTTP hook に `"onFailure": "block"` を付けると、起動失敗・時間切れ・0 と 2 以外の終了コード・不正な出力で失敗した hook が操作を止める。既定は従来どおり「失敗しても操作は続く」。**本リポの `.bat` / `.ps1` hook は「Python が無い環境では失敗して素通りし、ハードなガードは permission 側が担う」設計**（`.claude/rules/win-file-encoding.md`）。`onFailure: "block"` を付ければ hook 側でも止められるようになるが、Python 不在環境で `.ps1` 編集が全部止まる副作用があるので採否は別途判断
- **「Exit code output」**を終了コード × 標準出力の表に書き直し。hooks-guide の「Debug techniques」は「Check what a hook did」に改称
- HTTP hook は 2xx 以外のステータスで non-blocking error（`onFailure: "block"` で block にできる）
